# 内容资产健康检查清单

`/lint` 使用本清单做轻量健康检查。默认只输出问题和建议，不大规模改写旧内容。

## 主索引

- [ ] 已发布作品是否都进入 `00-内容资产索引/内容主索引.md`？
- [ ] `content_id` 是否唯一？
- [ ] 数据文件、成品指针、复盘/方法论是否能互相追溯？
- [ ] `03-已发布归档/已发布成品/` 的成品数是否与平台公开作品数一致？
- [ ] 每个已发布成品是否保存了实际发布文案，而不是只有数据文件指针？
- [ ] 平台数据文件是否都绑定了唯一 `content_id`，且没有未映射文件？
- [ ] 图文正文缺失项是否明确标记“待补”，没有拿相近草稿冒充？
- [ ] 当前创作中文件是否有状态：选题收集、脚本创作中、已发布、复盘完成、废弃、待处理空稿？

## 来源原文库

- [ ] `06-来源原文库/` 中新增来源是否登记到 `SOURCE_REGISTRY.md`？
- [ ] 来源是否只作为原文保存，没有被直接改写？
- [ ] 已评估来源是否标记抽取状态？
- [ ] 已抽取来源是否写回到 `02-素材知识库/` 或 `05-方法论沉淀/`？

## 素材知识库

- [ ] 是否存在重复概念或同义概念未合并？
- [ ] 金句是否有来源和适用场景？
- [ ] 案例是否绑定 `content_id` 或 `source_id`？
- [ ] 结构模板是否有适用平台和适用选题？

## 方法论

- [ ] 方法论中的数据是否与 `04-数据与复盘/` 冲突？
- [ ] 标题、开头、脚本结构、复盘规则是否仍可调用？
- [ ] 是否存在过期结论没有标注更新时间？
- [ ] 是否有新的复盘结论还没写回？

## 搜索卫生

- [ ] 默认 `rg --files` 是否排除了 `90-工具项目/`、`node_modules/`、`out/`、`tmp/`？
- [ ] 默认 `rg --files` 是否能看到 `06-来源原文库/`？
- [ ] 根目录是否只保留规则入口、索引入口和必要配置？
- [ ] `03-已发布归档/` 是否只存在 `已发布成品/`，没有重新创建 `草稿归档/`？
- [ ] `03-已发布归档/` 是否出现“根目录整理”、迁移清单、未命名 Canvas/Base 等整理中间产物？
- [ ] 外层冷备份是否保持在 DailyWrite 项目目录之外，并保留可恢复的迁移记录？
