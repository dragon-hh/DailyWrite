# 来源原文库

这里是 DailyWrite 的 Raw sources 层，用来保存原始资料和历史原稿副本。

## 原则

- 原文默认不改写，只登记、引用和抽取。
- LLM 可以读取这里的内容，但正式沉淀要写入 `02-素材知识库/` 或 `05-方法论沉淀/`。
- 原文和编译后的 wiki 不混放，避免把外部资料误当成个人方法论。

## 子目录

- `外部资料/`：外部文章、PDF 转文本、参考方法论、行业资料。
- `历史原稿/`：未来可放旧稿副本，用于回溯和抽取，不直接改原稿。
- `SOURCE_REGISTRY.md`：来源登记表，记录来源状态和抽取状态。

## 三层关系

- Raw sources：`06-来源原文库/`
- Wiki：`02-素材知识库/`、`05-方法论沉淀/`
- Schema：`SOURCE_OF_TRUTH.md`、`AGENTS.md`、`CLAUDE.md`
