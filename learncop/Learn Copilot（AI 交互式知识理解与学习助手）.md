Learn Copilot（AI 交互式知识理解与学习助手）
1.1一句话定位 把任意学习资料（文本/链接/笔记）变成可视化知识图谱 + AI 反向提问 + 理解度仪表盘的学习系统，帮助用户从“看懂”走到“学会”。
1.2核心需求 把零散资料结构化（知识点树/依赖关系） 通过 AI 提问验证“是否真的理解” 可追踪学习进度与薄弱点，指导复习 要想变成一个真正好用的，能提高学习效率的应用，么
 1. 智能学习路径生成

**现状问题**：知识图谱只是"地图"，用户不知道从哪走、怎么走
**解决方案**：
- **前置知识检测**：自动识别"要学 A 必须先会 B"（例如：学导数前需要理解极限）
- **个性化路径**：基于用户已掌握知识点 + 目标，生成"最优学习顺序"
    - 示例：目标是"理解神经网络" → 路径：线性代数 → 概率论 → 梯度下降 → BP 算法
### 📌 2. 分层提问机制

**现状问题**："AI 提问"如果只停留在"知识回忆"层面，无法测试真正理解

**解决方案**：参考**布鲁姆分类法**设计 3 层问题

| 层级    | 问题类型  | 示例（以"神经网络"为例）        |
| ----- | ----- | -------------------- |
| L1：记忆 | 定义/术语 | "什么是反向传播？"           |
| L2：理解 | 解释/关联 | "为什么梯度消失会影响深层网络训练？"  |
| L3：应用 | 场景/迁移 | "如果损失函数不可导，反向传播会怎样？" |
|       |       |                      |

**关键**：根据用户答题表现**动态调整难度**
- 连续答对 L1 → 自动升级到 L2
- L3 答错 → 重新巩固 L1-L2


### 📌 3. 薄弱点闭环：靶向练习 + 间隔重复

**现状问题**：识别薄弱点后没有后续动作
**解决方案**：

- **自动生成练习题**：针对错误知识点生成变式题目
    - 示例：用户对"导数的链式法则"理解不足 → 生成 5 道不同函数复合求导题
- **间隔重复算法（Spaced Repetition）**：
    - 借鉴 Anki 的 SM-2 算法，在遗忘临界点前主动推送复习
    - 示例：今天学会了"贝叶斯定理" → 1 天后/3 天后/7 天后自动复习提醒

### 📌 4. 即时反馈与成就系统

**现状问题**：学习过程枯燥，缺少正向激励
**解决方案**：
- **实时理解度可视化**：
    - 每个知识点显示"掌握度百分比"（基于答题正确率 + 复习次数）
    - 知识图谱节点用颜色区分：🟢 已掌握 / 🟡 学习中 / 🔴 薄弱
- **游戏化元素**：
    - 学习连续天数（Streak）
    - 里程碑徽章："完成微积分基础章节" / "连续 7 天学习"
    - **关键**：成就必须与真实学习进度强绑定，避免虚假激励
