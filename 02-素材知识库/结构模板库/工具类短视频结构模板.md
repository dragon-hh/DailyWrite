# 工具类短视频结构模板

## 清单模式

适合：工具推荐、插件盘点、Skill 推荐。

```text
痛点钩子：你装了 X，但发现它不够好用
筛选背书：我从 N 个里筛出这些
编号清单：每个工具一句定位 + 一个具体用途
收尾：收藏/评论领取清单或配置
```

## 教程模式

适合：安装、配置、接入国产模型、解决报错。

```text
强结论：这个工具现在普通人也能用了
卡点解释：以前为什么用不起来
步骤正文：三步或五步，少讲废话
价值补充：装完之后能解决什么真实问题
收尾：资料、配置、避坑说明
```

## 叙事模式

适合：Agent 团队、自动化工作流、真实案例。

```text
个人行动：我研究/搭建/实测了一个东西
先看结果：用画面证明它跑通了
任务过程：我只说一句话，系统自动拆解
原理简讲：30 秒解释机制
意义收尾：这件事说明未来怎么变
```

## 开头红线

- 不要上来就讲术语。
- 不要先介绍背景再进入痛点。
- 不要让观众等到第 10 秒才知道你要讲什么。
