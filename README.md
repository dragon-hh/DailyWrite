# DailyWrite 内容基地

这是个人内容生产与复盘工作区，核心用途是服务抖音短视频和小红书图文/短视频创作。

当前系统采用轻量内容资产结构：

- `00-内容资产索引/`：全局主索引、创作状态、检索与写回规则。
- `01-内容生产/`：选题、脚本创作、待拍摄。
- `02-素材知识库/`：可复用概念、金句、案例、结构模板。
- `03-已发布归档/`：已发布成品与历史草稿归档。
- `04-数据与复盘/`：平台数据、单条作品数据、复盘材料。
- `05-方法论沉淀/`：标题、开头、脚本结构、复盘规则、平台差异。
- `06-来源原文库/`：外部资料和历史原稿副本，作为不可直接改写的 Raw sources。
- `90-工具项目/`：Remotion、临时输入、旧工具副本等非内容主资产。

## 工作原则

1. 写稿前先查 `00-内容资产索引/内容主索引.md`，再查 `02-素材知识库/`。
2. 已发布作品必须绑定 `content_id`，并连接脚本、数据、复盘和素材写回。
3. 旧稿不直接删除；先归档、标记状态，再逐步抽取为素材或方法论。
4. 工具项目、依赖、缓存、临时文件不参与内容检索。
5. 原始来源放在 `06-来源原文库/`；LLM 编译后的可复用资产才写入 `02-素材知识库/` 和 `05-方法论沉淀/`。
