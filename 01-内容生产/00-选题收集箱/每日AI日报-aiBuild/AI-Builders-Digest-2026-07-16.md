### Training Data：Anthropic's Katelyn Lesse & Angela Jiang: Building an Ecosystem, not a Walled Garden

**核心结论：Anthropic 正把 AI 平台从“给模型知识”推进到“让模型执行”，下一站则是让不同 token 和 agent 按角色协同的 coordination layer。**

负责 Anthropic Platform 的 Katelyn Lesse 与 Angela Jiang 把平台抽象成三层。底层是 knowledge，包括 Messages API、工具、skills、memory 和 MCP；中间是 execution，用低层 harness、sandbox、会话存储和托管基础设施支撑长时间运行的 agent；顶层是 coordination，通过可组合的 strategies 给 token 分配不同工作，例如建议、执行、探索或审查。Angela 用一句话概括这种设计：**“the token has a job.”**

她们强调，Anthropic 想建设生态而不是围墙花园。内部产品和外部开发者尽量使用同一套 primitives，新能力既在内部 dogfood，也向外部客户开放早期测试，避免平台只适配单一用户群。MCP 的意义也不只是连接工具，它还能把一个 agent 暴露成另一个 agent 可调用的能力，让不同模型、平台和专用 agent 以模块化方式协作。

更实际的焦点正在从“消耗更多 token”转向“每美元获得更多 intelligence”。她们不建议企业用硬性额度压住员工的 AI 使用，而是先判断任务复杂度：难题交给大模型，简单任务路由给更便宜的模型，并让 harness 针对具体模型家族调优。眼下最有价值的创新集中在 context 与 connectivity，包括整合分散权限和数据、用 computer use 接入没有 API 的旧系统，以及把制造业、医疗和后台流程变成可执行的 agent 工作流。Anthropic 接下来要降低多 agent 策略投入生产的门槛，让开发者除了换更大模型、跑更久之外，还能通过角色分工和 best-of-N 等策略提升结果。
