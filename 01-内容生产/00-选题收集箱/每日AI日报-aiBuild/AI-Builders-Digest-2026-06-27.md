### Claude Blog: Building intelligent apps for Apple platforms with Claude in the Foundation Models framework

Claude Blog 发布了面向 Apple Foundation Models framework 的 Claude 支持：通过新的 Swift package，Apple 开发者可以先用 Apple 的 on-device models 做快速本地任务，比如摘要或抽取，再把需要多步推理、代码生成、web search 或数据分析的请求交给 Claude。关键点是 Apple 的 framework 可以用 `@Generable` 返回 typed Swift values，开发者传给 Claude 的不是原始用户文本，而是更干净的结构化输入。

这会让 Apple 平台上的智能应用更像“多模型路由”：journal app 可以先在本地生成日记 prompt，再让 Claude 跨月份寻找线索；学习 app 可以先本地解释术语，再在学生追问“这为什么重要”时交给 Claude 做更深推理。支持将在 iOS 27、iPadOS 27、macOS 27、visionOS 27 和 watchOS 27 上可用，开发者添加 package、用 Anthropic API key 登录后，即可把 Apple on-device pass 的 typed outputs 传入 Claude request，package 处理 streaming、tool calls 和 structured responses 回到 SwiftUI view。

### The MAD Podcast with Matt Turck: Cloudflare CEO: Bot Takeover, Edge AI & The Hard Decision Every CEO Will Face

The Takeaway：Cloudflare CEO Matthew Prince 的判断是，AI agent 已经让互联网从“人类访问网页”的世界，快速转向“机器大规模访问资源”的世界，而这会同时重写基础设施、广告商业模式和公司组织结构。

Matthew Prince 是 Cloudflare cofounder and CEO，Cloudflare 位于全球大量互联网流量前面，所以他看到的不是抽象趋势，而是流量层面的变化。他说 Cloudflare 数据显示，bot traffic 在 2026 年上半年已经超过 human traffic。更夸张的是他的预测：五年后，互联网流量可能达到今天的一千倍，因为一个 agent 为了完成同样的购物任务，可能访问 5,000 个网站，而人类只会访问 5 个。

这直接击中互联网旧商业模式的软肋。Prince 的一句话很适合放在这里：“The problem is bots don't click on ads.” 如果 bot 不点广告，而又制造了大量服务器、网络、CPU、GPU 和内存需求，那么互联网需要新的付费和价值分配机制。他还提到，brand 在 agentic world 里也会变：品牌过去是给人类的经验捷径，但 bots 有无限耐心去发现所有替代选择。

对 builders 来说，这不是“多一些 crawler”的问题，而是 product、infra 和 go-to-market 的共同重构。Cloudflare 自己也因此越来越像 AI infrastructure company：从安全、性能、edge network、Workers，到 AI Gateway 和 agent security，核心问题都变成了如何在机器流量占主导的网络里识别、控制、计费和分发价值。
