### Claude Blog: New in Claude Managed Agents: dreaming, outcomes, and multiagent orchestration

Claude Blog 发布了 Claude Managed Agents 的三类新能力：dreaming、outcomes 和 multiagent orchestration。Dreaming 是一个研究预览功能，会定期回顾 agent sessions 和 memory stores，提取模式、整理记忆，让 agent 在会话之间自我改进；它能发现单个 agent 不容易看见的跨会话模式，比如重复错误、常见 workflow、团队共享偏好，并把 memory 保持在更高信噪比。

Outcomes 则让开发者写出“成功长什么样”的 rubric，由独立 grader 在自己的 context window 里评估 agent 输出，指出问题后让 agent 再做一轮。Claude Blog 给出的内部测试结果是：outcomes 在标准 prompting loop 基础上最多提升 10 个百分点的 task success，docx 文件生成任务提升 8.4%，pptx 文件生成任务提升 10.1%。Multiagent orchestration 允许 lead agent 把复杂任务拆给多个 specialist agent 并行处理，共享 filesystem，并通过 Claude Console 追踪每一步。文中还提到 Harvey、Netflix、Spiral by Every、Wisedocs 等团队如何用这些能力做法律文档、构建日志分析、写作 agent 和文档质检。

### The MAD Podcast with Matt Turck: OpenAI's Dan Roberts: Why AI Can Now Make Discoveries

核心 takeaway：Dan Roberts 认为，AI 进入科学发现并不会出现一个突然的分水岭，而是随着 test-time compute、reasoning 和 reinforcement learning 的发展，逐步从“帮人做事”走向“能自己沿着长推理路径探索问题”。

Dan Roberts 是 OpenAI foundations of reinforcement learning team 的负责人，背景很特别：他从 MIT 理论物理博士、量子引力和量子信息研究，转向用物理学工具理解 deep learning，后来加入 OpenAI 做 reasoning 和 RL 的基础研究。他最值得注意的观点是：AI 在数学和科学里真正变强，不只是因为会复述训练数据，而是因为它可以在测试时投入更多计算，沿着一条不确定但可能有价值的路径持续推理。

他用近期数学问题的例子解释了这种能力：有些猜想大家默认是真的，但 ChatGPT 能做的一件事是“assume it was false”。这很反直觉，因为要逆着主流假设走很长的计算路径，需要强 conviction，也需要跨领域知识，比如把一个问题连接到 algebraic number theory。Roberts 对 OpenAI 与 DeepMind 路线的区分也很清楚：DeepMind 的方法更偏 Lean 等 formal language 中的自动形式化和证明搜索，优点是验证更严密；OpenAI 更多是在 informal math setting 里，用自然语言和数学表达像人类数学家一样给出证明，但验证更难。

谈到 RL，他给的通俗解释是：只看别人玩游戏是 supervised learning，自己按按钮、犯错、从环境和 reward 学习才是 reinforcement learning。RL 的强大来自环境反馈，但难点也在反馈稀疏：如果你要做很多步，最后才知道成败，就很难知道中间哪一步真的有用。这正是 reasoning model 和科学发现最核心的挑战之一。
