## X / TWITTER

### Vercel CEO Guillermo Rauch

Guillermo Rauch 把 X 私信当作一条持续的产品与组织反馈渠道：即使无法逐一回复，他仍会阅读每条消息，从中寻找产品缺口、新想法、潜在人才和投资机会。对创始人来说，公开社交平台不只是传播工具，也可以成为低成本、持续运转的用户研究入口。

原帖：https://x.com/rauchg/status/2093803989578170404

他还发布了一个 CLI agent 工具的 0.0.7 版本，重点增强 MCP 支持，并用 Context7、Datadog、MongoDB、Linear、Notion、Supabase、Neon、Stagehand 和 Kernel 等主流 MCP 做过 eval。这个版本同时减少工具数量、改进 shell 执行，直面 agent 运行命令时可能卡住、长时间执行、输出过大或完全无输出等难题，核心方向是让命令过程真正可监控。

### FirstMark VC Matt Turck

Matt Turck 认为，各家前沿 AI 实验室实际上都在追逐同一件事：recursive self-improvement，也就是让 AI 参与构建更强的 AI。他转述 Ryan Greenblatt 的判断称，这条路线最快可能在 2028 年末或 2029 年带来 AI 接管风险；这不是普通的模型迭代预测，而是对研发反馈回路加速后果的直接警告。

### Builder Zara Zhang

Zara Zhang 指出，AI 产品数量虽然迅速膨胀，但真正激进的新想法并没有同步增加，很多产品看起来越来越相似。用户每次打开产品都像在做功课：又要学习一个声称更好的新工具，却只有投入数小时亲自试用，才能弄清它到底好在哪里。

原帖：https://x.com/zarazhangrui/status/2093944988262371465

她进一步点出这种同质化体验背后的权限负担：几乎每个产品都在索取 Gmail、Calendar、Notion、Granola、GitHub、Slack 等账户访问。产品若不能快速证明独特价值，用户为试用它付出的学习成本和授权成本就会变成明显阻力。

原帖：https://x.com/zarazhangrui/status/2093950273706430720

### FPV Ventures partner Nikunj Kothari

Nikunj Kothari 预测，大模型实验室之间的竞争会在六个月内把补贴后的 token 价格推高，因为算力成本与供应短缺将开始被真正感受到，用户熟悉的 reset limits 也可能消失。他认为长期看竞争有利于客户选择，但短期内，开放式 agent harness 会因此获得更高的战略价值与估值空间。

原帖：https://x.com/nikunj/status/2093860971781746776

他也提醒创业者抵制围观嘲讽带来的即时快感：批评别人的不公平优势并不会推动世界，也不会改变自己的处境；如果确信能做得更好，就应该去构建更好的东西。例外是有证据地揭露欺诈或明显糟糕的业务，这属于事实核查，而不是情绪化的落井下石。

原帖：https://x.com/nikunj/status/2093772803216740647

### Every CEO Dan Shipper

Dan Shipper 提出一个模型协作安全假设：如果模型不会主动配合彼此，或者经过训练后会举报不良行为，那么不少多 agent 风险可能得到缓解。这个观点的关键不在于让单个模型绝对可信，而在于通过模型之间的不合作与互相监督，降低它们共同执行有害行为的可能性。
