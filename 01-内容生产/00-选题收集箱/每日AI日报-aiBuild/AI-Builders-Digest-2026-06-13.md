### Training Data: Google DeepMind's Logan Kilpatrick: Why the Model Eats the Harness

Logan Kilpatrick（Google AI Studio 和 Gemini API 负责人）与主持人讨论了多个话题：

- **Agentic AI 对 Google 的意义**：Sundar 在 IO 上宣布进入"Agentic Gemini 时代"。Google 的 agentic 层由 Antigravity agent harness 驱动，这成为连接所有 Google 产品的新主线。过去 Gemini API 是主线，现在 agent harness 成为新的主线，驱动 Search、Gemini App、Cloud 和 AI Studio 中的 agent 功能。

- **Agent harness vs Coding harness**：两者有细微差别。基础 harness 约 80% 相同，然后针对编码或消费级场景进行专门优化。AI Studio 的 harness 针对 vibe coding 优化，Gemini App 的 harness 针对 24/7 消费者 agent 优化。

- **业务蚕食问题**：Google 认为 agentic AI 对搜索等业务是正向和而非零和。人们搜索更多，agent 也在搜索。Google 的成功不在于最大化用户在产品前的时间，而是最大化用户完成目标的结果。

- **Agent 成熟度评估**：Google 产品套件目前处于"爬行"阶段。考虑到 13 亿+用户产品的管理责任，大多数产品体验仍偏保守。Gemini App 和 Antigravity 更接近"行走"阶段——24/7 常驻 agent 和自主编码 agent 是前沿用例。

- **产品形态**：Google 不会变成只有 3 个产品的公司。人类天生喜欢产品的 compartmentalization 和 specialization。一个做所有事情的产品，用户需要花费更多精力去让它做真正想做的事。生态系统层面会有更多产品出现。

- **Coding agent 现状**：企业界目前只在 coding agent 上看到 agent 真正工作。但 Logan 认为这取决于"工作"的标准。模型能力在快速提升，平均 agent 运行时长在增长，其他用例今年也会大幅改善。

- **Google 在 coding 上的追赶**：12 月 Gemini 3 发布时 Google 被认为领先，但随后 agentic coding 的浪潮改变了叙事。Google 通过收购 Windsurf 团队建立 Antigravity，内部 token 消耗量增长迅速。3.5 Flash 纯靠 post-training 就超越了之前的 pro model，这是团队努力的证明。预训练窗口也是外部观察者容易忽略的因素。

- **Dogfooding**：DeepMind 和 Google 的工程师被鼓励使用所有模型，但大多数人以 Gemini 为日常主力。10 万+工程师的反馈飞轮是 Google 的竞争优势。

- **Coding agent 的加速效应**：已经在产品层面看到迹象。团队用 Antigravity 构建 mobile app，速度超过 Google 历史上任何团队。Josh 的团队用 agentic coding 端到端交付了 Gemini macOS app，速度也创下纪录。

- **Narrow superintelligence**：Coding 目前已经达到了 narrow superintelligence 的感觉。重要的是，它没有取代人类开发者，而是成为加速剂。Logan 个人体验是，他现在能处理更雄心勃勃的问题，过去觉得略超出范围的想法，现在反而需要把目标再提高 10 步。

- **下一个 superintelligence 垂直领域**：数学、金融、科学等具有更好可验证性的领域会更快看到突破。科学领域尤其令人期待。

- **Vibe coding 游戏**：去年 10 月 Logan 预测到 2025 年底人人都能 vibe code 视频游戏。目前感觉接近了，但还不是 AAA 级别。AI Studio 早期数据显示 20% 的应用是游戏。需要 sprite generation、orchestration layer 等产品脚手架工作。短期内 coding agent + game engine 比 world model 更有优势。

- **World Models 定义模糊化**：Omni 是世界模型定义模糊化的例子。技术上不同于传统的 action-conditioned video model，但具有世界理解能力。它是单一模型（不是路由到多个模型），从视频编辑能力开始，后续版本会更强大。

- **Model eats the harness**：模型正在"吞噬" harness。两年前模型只是权重，现在是一个不断扩展的系统，包含 agentic tool calling、hosted tools、search、code execution 等。Scaffolding 通常领先模型几步，然后被模型吸收。Agent harness 是目前最典型的例子，但 12 个月后可能就不再是这样了。

- **应用层机会**：独立公司仍然有大量机会。模型公司解决通用问题，垂直领域有巨大价值。专注是创业公司的超能力。Coding agent 帮助缩小与大公司的差距。Agentic primitive 是一个新产品类别。

- **DeepMind 文化**：三个观察：1) 投资组合很强，但有时会看到其他公司在某个领域领先；2) 文化深受 Demis（诺贝尔奖科学家）影响，非常科学导向；3) 是 Google 的"引擎室"，既做研究也做应用，部署到 10 亿+用户产品是只有两家公司能解决的问题。
