## PODCASTS

**No Priors: Building an AI Guardian for Enterprise with Onyx Security CEO Maxim Bar Kogan**

Onyx Security 是以色列初创公司，由研究人员、数学家和工程师组成，专门构建"监视 AI agent 的 agent"。CEO Maxim Bar Kogan 与 No Priors 的 Adam 深入探讨了企业 AI 安全的现状与未来。

**核心观点：**

- **企业 AI 风险呈指数级增长**：随着 agent 能力的提升，agent 意外发布代码和 token 的事件频发。企业意识到无法阻止 AI 采用，只能设法降低 agent 行为非法或错误的风险。

- **三类企业 AI 部署现状**：
  1. 低代码自动化平台（约 45%）——drag & drop 构建，非真正自主 agent
  2. 第一方自建 agent（约 2%）——企业自行开发，难度最高
  3. 自主编码 agent（超过 50%）——如 Cloud Code、Cowork、OpenCLO，增长最快且通常缺乏控制

- **传统安全工具失效**：身份安全、端点安全、API 安全等传统工具无法理解 AI 系统的"思考过程"——它们不知道 Cloud Code 为什么要删除数据库。当 agent 拥有广泛权限时，传统权限控制反而阻碍了生产力。

- **Onyx 的解决方案——AI 控制平面**：
  - 训练专门的模型来监督其他 agent
  - 使用"小模型"快速判断是否需要"大模型"介入——类似国际象棋中的直觉判断 vs 深度计算
  - 目标是低成本、低延迟、高可靠性

- **Mythos 级别模型的安全挑战**：自动化漏洞研究的能力正在突飞猛进。企业需要快速修补漏洞，但更重要的是建立基础安全机制——身份锁定、防火墙、端点检测，以及专门针对 AI 攻击面的安全解决方案。

- **为什么不是 OpenAI/Anthropic 来做？**：
  - 企业不愿将历史数据交给数据饥渴的模型厂商
  - 安全需要独立第三方——就像买车不会找卖家做质检
  - 未来将是多模型、多厂商的异构环境，不可能依赖单一厂商提供安全保障

- **长期愿景**：不只是企业安全，而是"如何控制高级 AI"。随着模型变得更智能，它们会有更多独立"意识"，安全挑战将从"防止愚蠢错误"转向"确保 AI 的意图与人类一致"。

- **以色列安全生态优势**：深厚的对抗性思维、对安全团队日常工作的深刻理解、数学与网络安全的交叉背景。
