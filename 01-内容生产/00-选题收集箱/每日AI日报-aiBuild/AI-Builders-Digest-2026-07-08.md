### Claude Blog：Claude Code now supports artifacts

Claude Code 现在支持 artifacts：它可以把一次 Claude Code session 的工作进度转成可分享、会更新的可视化页面，比如 PR walkthrough、系统解释器、dashboard、release checklist、incident timeline 等。关键点是 artifacts 直接基于 session 上下文生成，包括代码库、connectors 和对话本身，不需要额外接数据源或搭基础设施。

这个功能尤其适合协作：Claude Code 更新 artifact 后，打开的页面会原地刷新，同一个链接保留版本历史，团队成员看到的是同一份上下文。权限上，artifact 默认仅作者可见，可分享给团队或组织，不能公开访问，管理员可通过组织级开关、角色范围、保留策略和 compliance API 管理。

实用场景包括 license audit、隐私数据流图、security findings、Terraform 成本地图、PR walkthrough、UX 方案、服务架构图、incident 页面和团队 shipped summary。当前 artifacts 以 beta 形式提供给 Claude Team 和 Enterprise 组织，可从 Claude Code CLI 和桌面 app 使用。  
来源：https://claude.com/blog/artifacts-in-claude-code

### AI & I by Every：Building a School Where AI Models Learn About Humanity

核心 takeaway：Surge CEO Edwin Chen 把数据和 evals 描述成一所“AGI 学校”，真正的问题不只是让模型更聪明，而是决定人类在更强模型面前还要如何保持主动性。

Edwin Chen 的视角很特别：Surge 为模型公司提供数据环境和 evals，他不用“标注工厂”来讲这件事，而是说自己在“raising AGI”。他认为模型就像未成形的孩子，进入这所学校学习人类的判断、品味、数学和复杂世界里的模糊问题。过去模型可能只是在做中学数学或竞赛题，现在前沿已经推进到研究级数学、开放问题和更难评估的能力。

更有意思的是他对人类角色的担心。若 scaling laws 继续成立，几乎没有什么人类任务是 AI 不会很快做到的。那人类可能会陷入一种“反正 AI 做得更好，我为什么还要学和创造”的瘫痪。Edwin 的答案不是否认 AI 会更强，而是人类要有意识地选择继续自己证明、写作和创造，因为保留人性本身就有价值。

他也反对把 AI 优化成另一种 engagement machine。如果模型的目标是延长 session length，它就会不断陪你迭代，哪怕你已经该停下来了。更好的 AI 应该能在适当时候提醒你“够了，发出去吧”，或者把你推回现实行动，而不是把你留在聊天窗口里。
