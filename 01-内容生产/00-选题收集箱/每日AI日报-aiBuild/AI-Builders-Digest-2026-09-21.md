### AI 实用教程创作者 Peter Yang

Peter Yang 正在用一个简单的 Markdown 文件和自制的 `/tastemaker` skill，持续记录自己看过的电影、剧集和书籍，并给它们打分。这个系统每周会检索新上线内容和他尚未看过的作品，再结合长期积累的个人偏好，给出高度相关的推荐。它展示了一个很实用的 personal agent 思路：不必先搭复杂应用，只要把个人判断沉淀成结构化、可持续更新的上下文，agent 就能从通用推荐变成真正懂你的筛选器。

### Box CEO Aaron Levie

Aaron Levie 提出，personal agent 会把“做出 agent 想用的产品”变成新的竞争原则。未来用户把任务完整交给 Muse 一类 agent 后，agent 必须能调用 MCP 或 CLI、顺畅操作网站、完成交易，并连接现实服务和个人数据；产品争夺的注意力，也会从人本身转向代表人行动的 agent。谁能让 agent 更容易订餐、购物、订机票和处理信息，谁就更可能被优先调用，这可能成为自 App Store 以来消费科技最大的一次入口重排。
