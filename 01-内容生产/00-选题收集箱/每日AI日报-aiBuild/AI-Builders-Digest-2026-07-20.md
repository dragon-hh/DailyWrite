### The MAD Podcast with Matt Turck
**Stripe's AI Chief: How AI Agents Will Buy, Sell, and Pay**

嘉宾：Emily Sense（Stripe 数据与 AI 主管）。这是一场延续自去年同题的深度对话——去年大家主要在第一性原理层面讨论 agentic commerce，今年已经出现真实的部署、合作伙伴与可学习的 pattern。本期要点：

- **光谱而非单一形态**：agentic commerce 是一条光谱。一端是 agent 全自主发现服务并完成交易（Stripe 的 machine payments protocol 所在之处），另一端是人在 AI surface 里被推荐商品、点"buy"按钮——两者都需要新的基础设施。

- **Agentic Commerce Protocol（ACP）**：Stripe 与 OpenAI 联合推出（去年秋），核心是 (1) 让商家一次暴露商品目录 / 库存 / 价格，agent 接 ACP 即可，不用每个 agent 重接；(2) shared payment token：买家凭据 token 化、agent 永远拿不到真实卡号。整套机制平台无关、PSP 无关。

- **合作矩阵**：Google（Gemini / AI Mode 直接下单，JD Sports / Fanatics / Quince 等早采纳）、Microsoft + OpenAI（Copilot / ChatGPT）、Meta（广告内直接结账）。品牌端 Best Buy、Coach、URBN、Kate Spade 等已接；平台端 Wix、Shopify、BigCommerce、CommerceTools 全部接 ACP。

- **自主性分级（类似自动驾驶 L1–L3）**：L1 人类决策 + AI 执行；L3 agent 全自主。当前 consumer 端大多在 L2（人借助 AI 发现、agent 帮跑繁琐支付），B2B 端以及 agent-to-agent 间还有一些路要走。Emily 期待约 12 个月后能聊到 Emily 这个 agent 替 Emily 本人做买与卖的版本。

- **信任是头号瓶颈**：shared payment token（编码 merchant / 金额 / 币种 / 时长）、Link Wallet 把 Stripe 自家 3 亿用户的 wallet 变成 agent 的钱包，每笔交易里都带 Radar 评分，consumer 可以 set budget、按 merchant、按品类、按笔审批。"你给 agent 写的是带护栏的许可，不是空头支票。"

- **Vibe deployment**：vibe coding 的瓶颈已经不是写代码，而是 deploy。Stripe 文档流量 12 个月内来自 agent 的增长 >10x，现占约 40%；CLI 70% 的 API 请求来自 agent——多数"使用者"已经是 agent。Stripe 推出 **Stripe Projects**，让 agent 从 CLI 一站式开通 / 配置 / 集成 Vercel、Supabase、Cloudflare、Twilio、Clerk 等 16+ 合作伙伴，编排整条部署流水线；类比 agentic commerce 之于电商。

- **Token 偷窃（被 Emily 自己称为"最被低估的 AI 话题"）**：fraudster 不用再偷钱或偷卡号——直接偷 token。token 有真实价值，可被拿来 wrap 新产品、再出售。Stripe data：

  - **多账号滥用**：AI 公司超过 **1/6 的 signup** 属此类——同一群人批量开账号薅新用户额度。极贵。
  - **免费试用滥用**：6 个月内 Stripe 上 free trial abuse 翻倍，其中大多来自 AI 业务；已有"free trial card"24 小时卡这种灰色产业链。
  - **Dine-and-dash**：靠 usage-based 累积的月末大额账单最后不付。
  
  Stripe 因覆盖几乎所有 AI 买家与卖家（前述约 2% 全球 GDP）有前端视野，已把 Radar 评分内置进 shared payment token，把好与坏两端的信号对称地传给商家。

- **计量与定价**：token 时代边际成本不再接近 0，订阅制经济性破裂，必须转向 usage-based，但 hybrid 居多——订阅给入门消费者熟悉度，threshold 之上按 token 精细计费。Lovable、Eleven Labs 都是这条路径。Agent 的"机器速度"消费迫使**实时 metering + 链上支付**（Stripe × Metronome × Tempo）成为现实，agent 也不再依赖月底开账单。

- **下游对会计的冲击**：传统 Excel 月末关账对 microtransactions 行不通；新的会计岗位变成「会计师 + 工程师」混合角色，主要工作是扫异常、追诈骗、看 rev rec stack 解读业务健康 / 风控 / 产品破损。

- **宏观面**：AI 也降低了"开公司 + 持续运营公司"的门槛。美国 business formation 在疫情后曾 plateau，近几个季度重新加速，incremental 增长**完全来自 non-employer firms**（个人独资 / solopreneur）。目前约 500 万美国人以 solo company 为生并养家，其中数十万年收入超 100 万美元——"vibe coding + vibe deploying + 领域 agent 干客服与会计"让小公司结构性可活。
