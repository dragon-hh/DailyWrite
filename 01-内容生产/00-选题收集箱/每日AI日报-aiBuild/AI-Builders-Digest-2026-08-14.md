### Anthropic Engineering

#### An update on recent Claude Code quality reports

Anthropic 确认，近期部分用户感受到的 Claude Code 质量下降，来自三项彼此独立的产品层变更，API 和推理层没有受影响。第一项是在 3 月 4 日把默认 reasoning effort 从 high 降到 medium，以减少长尾延迟，但用户更愿意保留更高智能并自行选择低 effort；该变更已于 4 月 7 日撤销。第二项是清理闲置会话旧 thinking 的实现存在 bug，导致跨过一小时闲置阈值后每轮都继续丢弃历史推理，使 Claude 显得健忘、重复并做出异常工具选择；v2.1.101 已修复。第三项是限制工具调用间文字不超过 25 词、最终回答不超过 100 词的 system prompt，使 Opus 4.6 和 4.7 在一项更广泛评测中下降 3%，已于 4 月 20 日撤回。

最值得注意的原话是：“This was the wrong tradeoff.” Anthropic 承认，内部 usage 和原有 evals 起初没有复现真实用户问题。后续措施包括让更多员工使用与公众完全一致的 build、扩大每个模型的评测和消融范围、强化 system prompt 审计、增加 soak period 与渐进发布，并重置所有订阅用户的 usage limits。

https://www.anthropic.com/engineering/april-23-postmortem

#### Scaling Managed Agents: Decoupling the brain from the hands

Anthropic Engineering 介绍 Managed Agents 的核心架构：把“brain”即 Claude 与 harness、“hands”即 sandbox 与 tools，以及持久化 session log 拆成彼此独立、可替换的接口。文章的关键判断是，随着模型进步，写进 harness 的旧假设会过时，所以平台应稳定接口，而不是固化某一种 agent 实现。原话是：“The abstractions outlasted the hardware.”

拆分后，sandbox 宕机可以作为 tool-call error 返回，harness 崩溃也能根据外部 session log 恢复；凭证则留在 sandbox 之外的 vault 或网络边界，避免生成代码直接接触 token。session 也不再等同于 context window，而是可持久查询的完整事件流，让 harness 自由做 compaction、trimming 和 context engineering，同时保留可恢复的原始上下文。实际收益很具体：p50 首 token 时间下降约 60%，p95 下降超过 90%。对开发者而言，Managed Agents 更像一层 meta-harness，可把不同 harness、MCP server 和执行环境组合起来，而不把 agent 绑定在单个容器里。

https://www.anthropic.com/engineering/managed-agents

### Claude Blog

#### New in Claude Managed Agents: self-hosted sandboxes and MCP tunnels

Claude Blog 宣布 Managed Agents 新增 self-hosted sandboxes 和 MCP tunnels。前者处于 public beta，允许 agent 在企业自有基础设施，或 Cloudflare、Daytona、Modal、Vercel 等托管环境中执行工具；编排、上下文管理和错误恢复仍在 Anthropic 基础设施上运行，但代码、敏感文件、服务与数据留在企业边界内。企业可以沿用已有网络策略、审计日志和安全工具，并自行决定 CPU、内存与 runtime image。

MCP tunnels 处于 research preview，可让 Managed Agents 和 Messages API 连接私有网络内的数据库、API、知识库及工单系统，无需暴露公网入口。其核心机制是企业部署的轻量 gateway 只建立单向出站连接，文章原话为：“no inbound firewall rules, no public endpoints, and traffic encrypted end to end.” 实际意义是，企业可以把 agent 的“brain”托管出去，同时把执行环境、数据访问和安全控制继续留在自己的边界内。
