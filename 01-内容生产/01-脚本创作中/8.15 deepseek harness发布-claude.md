deepseek harness 以后可能会成为国内使用最广泛的harness

三天前,DeepSeek 干了一件比发布新模型更狠的事——开源了自己的Agent，DeepSeek Harness。不到三天,GitHub 标星破十万。这个动作的意思是,DeepSeek 不再只跟你卷参数和跑分了,现在要卷"模型怎么被用起来"这一层,这恰好是过去一年 Claude Code 这类产品建立护城河的地方。

先说人话,什么是 harness。这两年 AI 圈总说"模型即产品",但真相是,同一个模型,换一套Harness,表现能差出十万八千里。行业里现在有个说法:模型加 harness 等于智能体。
模型是大脑,harness 就是手和脚,二者组合起来才能真正干活。

DeepSeek Harness的设计哲学一句话:一切皆插件。
模型适配器是插件,工具注册是插件,会话管理是插件,连智能体循环本身都是插件,没有一个焊死的核心。底层靠一个叫 Cordis 的框架撑着。
很多人第一反应拿它跟 Claude Code 比。说实话没必要唱衰谁,思路不一样。Claude Code 相对固定,你在它划好的框架里接工具;
dsh 反过来,从模型适配器到沙箱到界面,理论上每一层都能单独换掉。一个开源、可拆、还在长身体,一个闭源、集成度高、已经很成熟。谁更适合你,取决于你要的是开箱即用,还是每个零件都攥在自己手里。
