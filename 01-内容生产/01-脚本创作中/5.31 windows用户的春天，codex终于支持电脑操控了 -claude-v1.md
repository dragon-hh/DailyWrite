

装了最新版 Codex，却发现 Computer Use 这个插件要么找不到，要么点了没反应——

我之前也是，差点以为是账号问题。

---


先说 Computer Use 能干什么。

普通的 AI 插件，只能操作浏览器，这没什么稀奇的。

但 Computer Use 不一样，它能操作你电脑上的**任何**应用——

替你发条微信、帮你打开剪映剪视频 、甚至帮你操作 Matlab 跑代码。


---



所以很多 Windows 用户更新完之后，第一件事就是去找这个插件。

然后就发现，要么压根搜不到，要么装上之后根本没反应。


---


原因只有一个，Codex 装在了非 C 盘。

Computer Use 要调用系统底层权限，只有装在系统盘才能正常工作。

解法三步，30秒搞定——

第一步，打开 Windows 设置，找「应用」，找到 Codex，点「移动」，把它迁移到 C 盘。

第二步，迁移完成后，重新打开 Codex。

第三步，再去找 Computer Use 插件，这次可以正常使用了。

---



我这里直接让它给我发一条微信——

跟它说，帮我打开微信，给「微信传输助手」发一条消息。

你可以看到，它先定位到微信窗口，打开搜索框，搜到这个联系人，输入内容，点发送。

整个过程是可视化的，你能全程看着它在操作。
