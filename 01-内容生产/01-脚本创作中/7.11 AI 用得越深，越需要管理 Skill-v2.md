标题：73 个项目，近 600 个 Skill，我是怎么管的
## 口播稿

我刚刚把电脑里的 Skill 全扫了一遍，结果有点离谱。

73 个项目，接近 600 个 Skill。

有些是全局的，有些只装给 Claude Code，有些在 Codex、OpenClaw 里，还有一些只在某个项目里生效。

最麻烦的不是数量多。

是我已经开始说不清，哪个 AI 到底会什么了。

所以我把一个开源的 Skill 管理项目拉到了本地。

它是一个本地 Skill 控制台。不同 Agent 装了什么、每个项目装了哪些 Skill，一眼就能看清。

目前支持所有主流agent平台，同时接入了各个大厂公开 Skill 仓库。
点击即可快速安装对应的skill。
点开 Skill，既能看原文件，也能让 AI 解释用途。

以前我也觉得，Skill 跟插件差不多，看到有用的就装。

但装到几百个以后，我才发现，安装只是最简单的一步。

一个写作 Skill 放在写作相关的项目里是经验，塞进所有项目里就是噪音。代码、写作、数据分析，需要的能力根本不是一套。

所以现在，我会把真正通用的 Skill 放进中央技能库，再按 Agent 和项目分配过去。

不过这个开源项目要真正放进我的工作流，还得再改一轮。

原版在 Windows 上，生成中文解释会一直转圈，还集成了WorkBuddy、OpenCode 等几十个我不太用的平台，非常冗余。

所以我让 Codex 修好bug，隐藏不用的平台，再调整一下配色。
到这一步，这套 Skill 管理流程才真正跑通。
