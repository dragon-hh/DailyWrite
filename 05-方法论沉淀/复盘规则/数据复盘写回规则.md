# 数据复盘写回规则

## 复盘字段

每条已发布内容至少记录：

```text
content_id:
播放:
完播率:
5s完播率:
收藏:
分享:
涨粉:
判断:
成功/失败原因:
写回素材库:
写回方法论:
下一条选题:
```

## 判断口径

- 收藏高：说明内容有工具书属性，优先沉淀步骤、清单、配置。
- 分享高：说明有社交货币，优先沉淀标题和选题包装。
- 完播高：说明叙事和节奏有效，优先沉淀开头和故事结构。
- 涨粉高：说明解决了目标用户的刚需，优先沉淀人群痛点和教程结构。

## 写回位置

- 概念：`02-素材知识库/核心概念库/`
- 金句：`02-素材知识库/金句语录库/`
- 案例：`02-素材知识库/个人故事库/`
- 爆款拆解：`02-素材知识库/爆款拆解库/`
- 稳定模板：`05-方法论沉淀/`
