# 抖音标题公式

## 目标

抖音标题优先解决：痛点、悬念、结果承诺、工具名识别。

## 已验证公式

1. `工具名 + 安装/配置 + 国产化关键词`
   - 适合涨粉和收藏。
   - 例：`Claude Code 安装以及配置国产模型教程`

2. `必装 X 个 + 工具/插件/Skill`
   - 适合传播和收藏。
   - 例：`OpenClaw 必装的十个 Skill`

3. `我搭了一个 X，它能自动做 Y`
   - 适合完播和叙事。
   - 例：`我搭了一个 7 人 Agent 团队，它们自动协作`

4. `新功能 + 具体结果 + 低门槛`
   - 适合追热点。
   - 例：`Claude 桌面端可以接国产模型了，三步配置`

## 生成要求

- 标题里必须出现工具名或明确结果。
- 少用泛化形容词，多用具体动作。
- 不为了悬念牺牲可搜索关键词。
