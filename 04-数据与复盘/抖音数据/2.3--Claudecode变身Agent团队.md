## 文案内容

AI 写代码总翻车？Anthropic 黑客松冠军教你如何拥有一个专业的“AI 团队”
**Everything Claude Code**
是一个针对全球最强智能体
`Claude Code` 的全面配置和增强套件。
它出自Anthropic 黑客松冠军之手。
它的目标是将一个通用的 AI 聊天编程助手，
转变为一个能够处理复杂工程任务、
具有长期记忆
且严格遵循开发标准的**高级开发智能体团队**。
该项目主要解决了直接使用 ai编程时的三大痛点
1、**上下文遗忘 (Context Amnesia)**
ai 通常“用完即忘”。
本项目通过持久化钩子（Hooks）保存项目特定的知识，实现越用越顺手。
2、 **Token 浪费 (Token Economics)**
为了避免每次都读取所有文件，
引入了专门的子代理和智能检索，只在需要时获取必要信息。
3、**质量失控 (Quality Control)*
强制执行工程标准（如 TDD 测试驱动开发、安全审查）
防止 AI 生成“能跑但难以维护”的代码。
接下来我带大家深度解析一下它的核心架构：
### 第一部分 Agent团队 
该项目目前包含 **13 个** 预定义的专业agent，
它们各司其职。
我们可以将它分为三类：
核心指挥层、通用工具人和领域专家。
核心指挥层有两个代理组成：
分别是：- **Planner (规划师)** :
项目的大脑。在编写任何代码之前，
它负责分析需求、制定步骤、识别风险并生成 `PLAN.md`。
-Architect (架构师) : 负责高层系统设计，
决定目录结构，选择技术栈，并生成架构图。
通用工具人 有六个，分别是：
- 审查员： 对暂存区的代码进行通用质量审查（包括逻辑、风格、最佳实践）。
- 测试向导 ： 专门负责引导测试驱动开发的流程。
- bug修复师 : 专门分析编译器报错或运行时错误，并提出修复方案。
- 重构清理师: 负责识别并删除死代码、优化冗余逻辑。
- 文档更新员: 确保 README、API 文档与代码变更保持同步。
- 端到端测试员： 负责生成和运行 Playwright 等 E2E 测试脚本。

1、安全审计师
专注于全球通用的 Web 应用**十大高危安全漏洞清单**、
密钥泄漏、注入攻击等漏洞的审查。
2、数据库专家
审查 SQL 查询性能、数据库设计和索引优化。
3、go语言审查专家
4、 Go语言修bug专家：
5、python语言专家
第二部分 持续学习，让claude拥有记忆
通过一套触发---观察---提取---存储--应用的自动化流程，让claude越来越懂你。
具体实现原理如下：
利用 `hooks` 机制，在每次会话结束时自动触发脚本。将本次会话的全部 Prompt 和 Response 发送给一个轻量级模型（如 Haiku）。
脚本会要求模型回答：“用户在这个项目中有什么偏好？我们学到了什么新的错误修复模式？”
例如：用户总是要求在 SQL 字段名上加反引号。
提取出的知识被保存为结构化的 JSON 数据或 Markdown 文件。
包含：模式内容、置信度分数、适用场景 
在下一次会话开始时，系统会自动读取这些记忆的文件，并将其注入到 Claude 的 System Prompt 。
第三部分 通过斜杠命令，封装常用工作流
项目中包含 **20多**个自定义命令，
按功能分可以分为四类：
1、核心开发工作流 (Core Workflows)
它强制执行**“计划 -> 测试 (TDD) -> 编码 -> 审查 -> 验证”**的严谨工程路径，确保新功能的代码质量从一开始就是可靠的。
2、修复与维护工作流
当项目出现bug自动修复，根据代码变更去更新文档，确保项目长期处于健康、整洁的状态。
3.特定语言工作流 
针对特定技术栈的“专家模式”，处理该语言特有的逻辑，往往比通用指令更有用
4、学习与进化工作流 
它不让经验随对话结束而消失，而是通过“学习”和“进化”指令，将零散的解决问题的经验固化为永久的“技能”或“直觉”，并能在团队间导入导出，实现知识共享。
