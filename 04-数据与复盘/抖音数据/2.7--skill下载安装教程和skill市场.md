## **为什么它比单纯的 Prompt 强得多？**

核心就八个字——**动态加载，渐进披露。**

整个过程是这样的：

当你安装 Skill 时，

Agent 并没有把几万字的说明书塞进上下文，

它只记录了 Skill 的名称和简介

当你问“帮我查一下数据库”时，

Claude Code 的路由器发现这匹配了 `database-skill` 的简介。

此时，系统才动态读取该 Skill 的详细操作手册和脚本。

执行脚本，获取真实反馈。

最后将执行结果返回给你。

**这套机制的精妙之处在于：**

Agent 拥有了**无限扩展的技能树**，  
但平时又保持**极度轻量的运行状态**。

用不到的知识不占资源，用到时瞬间满血加载。
