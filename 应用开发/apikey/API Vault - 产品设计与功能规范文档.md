

**版本:** 1.0

**日期:** 2026-01-31

**设计核心:** Apple-Style Minimalism (苹果极简主义), Glassmorphism (毛玻璃), Intelligent Automation (智能自动化)

## 1. 设计语言系统 (Design Language System)

本应用采用类似 macOS/iOS 系统设置的现代设计语言，旨在提供一种“理性的高级感”。核心视觉特征为：**通透、圆润、克制**。

### 1.1 色彩规范 (Color Palette)

- **全局背景 (Canvas):** `#F5F5F7` (macOS 浅灰底色)。避免使用纯白作为背景，以减少视觉疲劳并突出内容层级。
    
- **容器背景 (Surface):** `#FFFFFF` (纯白)。用于卡片和弹窗，配合低透明度以实现层次感。
    
- **主色调 (Primary):** `#0071E3` (Apple Blue)。用于主按钮、激活状态、光标和高亮文字。
    
- **文本颜色:**
    
    - 标题: `#1D1D1F` (接近纯黑的深灰)。
        
    - 次要信息: `#86868B` (中性灰)。
        
    - 代码/密钥: `#424245` (等宽字体颜色)。
        
- **功能色:**
    
    - 删除/破坏性操作: `#FF3B30` (Apple Red)。
        
    - 成功/安全: `#34C759` (Apple Green)。
        

### 1.2 质感与材质 (Materials)

- **毛玻璃 (Frosted Glass):**
    
    - 应用场景：顶部导航栏 (Header)、通知弹窗 (Toast)、模态窗口背景 (Overlay)。
        
    - 参数标准：`backdrop-filter: blur(20px)`，配合 `rgba(255, 255, 255, 0.8)` 的背景色。
        
- **阴影 (Depth):**
    
    - 采用“弥散光”风格，避免锐利的黑边。
        
    - 常态卡片：低半径、低透明度阴影。
        
    - 悬浮/弹窗：高半径、柔和阴影，模拟浮起效果。
        

### 1.3 形状与排版 (Shape & Typography)

- **圆角 (Corner Radius):**
    
    - 全局统一采用大圆角。
        
    - 卡片/弹窗：`24px` (Super Ellipse / 连续曲率圆角)。
        
    - 按钮/输入框：`12px` - `16px`。
        
- **字体 (Typography):**
    
    - 界面字体：系统默认无衬线字体 (San Francisco / Inter)。
        
    - 数据字体：等宽字体 (Monospace) 用于显示 API Key、Endpoint URL，确保字符对齐，增强由于技术感。
        

## 2. 界面结构与布局 (Interface Structure)

### 2.1 顶部导航栏 (Sticky Header)

- **位置:** 页面顶部固定。
    
- **状态:** 滚动时背景变为半透明毛玻璃，内容下方出现极细的分割线。
    
- **内容:**
    
    - 左侧：应用图标 + "API Vault" 标题。
        
    - 右侧：
        
        - **搜索框:** 胶囊形，灰色背景，聚焦时产生蓝色光晕。
            
        - **主操作按钮:** "+ New Key"，蓝色实心胶囊按钮，带微弱发光阴影。
            

### 2.2 内容区域 (Dashboard Grid)

- **布局:** 响应式网格布局。桌面端双列并排，移动端单列堆叠。
    
- **卡片设计:** 每个 API Key 为一个独立卡片，包含服务商 Logo、名称、Endpoint、密钥掩码区、操作区。
    

### 2.3 添加/编辑弹窗 (Modal)

- **交互:** 点击添加按钮后，背景变暗并模糊 (Blur Dimmer)，弹窗从屏幕中心轻微放大浮现 (Zoom-in Fade)。
    
- **布局:** 简洁的单列垂直表单，底部为操作按钮组。
    

## 3. 功能模块与交互逻辑 (Functional Specifications)

### 3.1 智能添加 Key (Smart Addition)

- **输入框逻辑:**
    
    - 包含：Service Provider (下拉选择), Name (文本), Endpoint (URL), Secret Key (密码框)。
        
- **自动识别 (Auto-Detection):**
    
    - 当用户在 "Secret Key" 输入框粘贴内容时，系统通过正则匹配前缀：
        
        - `sk-proj...` / `sk-org...` -> 自动选中 Provider 为 **OpenAI**，自动填充 Endpoint 为 OpenAI 官方地址。
            
        - `sk-ant...` -> 自动选中 **Anthropic**。
            
        - `gsk_...` -> 自动选中 **Groq**。
            
    - **目的:** 极大简化用户操作，只需粘贴 Key，其他信息自动补全。
        

### 3.2 密钥安全与展示 (Security & Display)

- **脱敏显示:** * 默认状态下，Key 仅显示前8位和后4位，中间使用点号 (`••••`) 或星号隐藏。
    
    - 示例: `sk-proj-ab•••••••••1234`。
        
- **查看明文 (Reveal):**
    
    - 交互：点击“眼睛”图标。
        
    - 逻辑：点击切换显示/隐藏。
        
- **一键复制 (Clipboard):**
    
    - 交互：点击“复制”图标。
        
    - 反馈：**必须**提供视觉反馈。
        
    - **动态岛通知 (Dynamic Toast):** 屏幕顶部中心向下滑出一个黑色胶囊提示框，显示“Copied to clipboard”，2秒后自动收起。禁止使用浏览器默认 `alert`。
        

### 3.3 管理功能 (Management)

- **搜索/过滤:**
    
    - 实时过滤 Key 列表。支持匹配“服务商名称”和“备注名称”。
        
- **删除:**
    
    - 为了防止误触，删除按钮默认隐藏或弱化（灰色）。
        
    - 鼠标悬停 (Hover) 卡片时，显示红色的删除图标。
        
    - 点击删除后，卡片应有收缩消失的动画，随后弹出 Toast 提示。
        

### 3.4 响应式适配 (Responsiveness)

- **Mobile:** * 搜索框折叠为图标，点击展开。
    
    - 卡片变为全宽。
        
    - Toast 通知显示在屏幕顶部或底部安全区。
        
- **Desktop:** * 利用宽屏空间，显示完整的搜索栏。
    
    - 卡片采用 Grid 布局。
        

## 4. 微交互细节 (Micro-interactions)

- **按钮点击:** 所有的可点击元素（按钮、卡片操作图标）在按下 (Active) 时，应有 `scale(0.96)` 的缩小回弹效果，模拟物理按键触感。
    
- **卡片悬浮:** 鼠标悬停在卡片上时，卡片背景略微变白（提升亮度），阴影加深并扩散，产生“浮起”的视觉暗示。
    
- **输入聚焦:** 输入框获取焦点时，边框颜色平滑过渡到主色调，并带有淡淡的同色系外发光 (Ring)。
