# 提示词收藏网站 - 需求文档

## 一、项目概述

### 1.1 项目名称

**PromptVault** — 高品质提示词收藏与分享平台

### 1.2 项目定位

一个面向 AI 用户的提示词管理与分享平台，用户可以收藏、管理自己的提示词，也可以将优质提示词分享到公共广场供他人发现和使用。

### 1.3 核心价值

- **个人管理**：提供私有提示词库，方便个人积累和复用
- **社区分享**：优质提示词可以公开到广场，形成社区生态
- **效果可视**：支持上传效果展示（图片/视频），让提示词效果一目了然
- **使用指引**：支持 Markdown 格式的使用说明，降低上手门槛
- **内容生长**：支持衍生创作，让优质提示词不断被改进和传播

| 扩展   | 支持 Google / GitHub 第三方登录 |
|      |                          |

#### 3.1.2 登录

|项目|说明|
|---|---|
|登录方式|邮箱 + 密码|

#### 3.1.4 用户个人主页

| 项目      | 说明                     |
| ------- | ---------------------- |
| 公开信息    | 头像、昵称、个人简介、加入时间        |
| 公开提示词列表 | 展示该用户所有公开的提示词          |
| 数据展示    | 公开提示词数量、获赞总数、被收藏总数、粉丝数 |


#### 3.1.5 角色

| 角色   | 说明                              |
| ---- | ------------------------------- |
| 游客   | 可浏览提示词广场（公开内容），不可上传、收藏、评价       |
| 注册用户 | 可上传、管理自己的提示词，浏览广场，收藏/点赞/评论他人提示词 |
| 管理员  | 后台管理，审核内容，管理用户                  |
### 3.2 提示词管理（核心模块）

#### 3.2.1 提示词数据结构

| 字段    | 是否必填   | 类型       | 说明                                                   |
| ----- | ------ | -------- | ---------------------------------------------------- |
| 提示词名称 | ✅ 必填   | 文本       | 最多 100 字符                                            |
| 提示词内容 | ✅ 必填   | 长文本      | 提示词正文，最多 5000 字符                                     |
| 所属文件夹 | ❌ 选填   | 关联       | 可选择放入一个或多个文件夹                                        |
| 分类    | ❌ 选填   | 单选       | 从系统预设分类中选择一个一级分类                                     |
| 标签    | ❌ 选填   | 标签（多选）   | 从预设标签中选择或自定义，最多 5 个                                  |
| 适用模型  | ❌ 选填   | 标签（多选）   | 如 ChatGPT / Claude / Midjourney / Stable Diffusion 等 |
| 效果展示  | ❌ 选填   | 图片或视频    | 图片最多 9 张（每张 ≤ 5MB），视频最多 1 个（≤ 50MB）                  |
| 使用方法  | ❌ 选填   | Markdown | 支持完整 Markdown 语法，实时预览                                |
| 公开状态  | ❌ 默认私有 | 开关       | 私有：仅自己可见；公开：展示到提示词广场                                 |
|       |        |          |                                                      |
| 衍生来源  | 自动     | 关联       | 若通过 Fork 创建，自动记录原始提示词的关联                             |
| 复制次数  | 自动     | 数值       | 统计该提示词被复制的次数                                         |
| 创建时间  | 自动     | 时间戳      | 系统自动记录                                               |
| 更新时间  | 自动     | 时间戳      | 修改时自动更新                                              |

#### 3.2.2 创建提示词

- 弹窗或独立页面形式
- 表单布局清晰，必填项有明确标识（红色星号）
- 提示词内容区域支持代码编辑器风格（等宽字体、行号显示）
- 效果展示支持拖拽上传、粘贴上传
- 使用方法区域提供 Markdown 编辑器，支持分栏实时预览
- 支持保存为草稿

#### 3.2.3 编辑提示词

- 可修改所有字段
- 修改后记录更新时间
- 公开状态可随时切换

#### 3.2.4 删除提示词

- 需二次确认弹窗
- 删除后不可恢复（V2 考虑回收站功能）

#### 3.2.5 提示词详情页

- **顶部**：名称 + 作者信息（可点击进入作者主页） + 发布时间 + 分类 + 标签
- **衍生标注**：若为 Fork 内容，显示「基于 @xxx 的提示词改编」，可点击跳转原始提示词
- **提示词内容区域**：带一键复制按钮（点击后按钮变为 ✓ 已复制，同时复制次数 +1）
- **效果展示区域**：图片轮播 / 视频播放器
- **使用方法区域**：Markdown 渲染展示
- **评论区域**：展示评论列表，支持发表评论和回复
- **底部操作栏**：点赞、收藏、Fork（基于此创建）、分享链接、举报
- **相关推荐**：底部展示「相似提示词」和「该作者的其他提示词」



#### 3.2.9 导入 / 导出

|项目|说明|
|---|---|
|导出|支持导出自己的全部提示词，格式：JSON / CSV|
|导出内容|包含：名称、内容、标签、适用模型、使用方法、创建时间|
|导入|支持 JSON / CSV 格式批量导入|
|导入校验|自动校验必填字段，导入结果报告（成功 N 条 / 失败 N 条）|
|导入去重|按提示词名称 + 内容去重提示，由用户决定跳过或覆盖|

### 3.4 互动功能

#### 3.4.1 基础互动

|功能|说明|
|---|---|
|点赞|每个用户对同一提示词只能点赞一次，可取消|
|收藏|每个用户对同一提示词只能收藏一次，可取消|
|一键复制|复制提示词内容到剪贴板，同时复制次数 +1|
|分享|生成提示词详情页的分享链接|

#### 3.4.2 评论系统

|项目|说明|
|---|---|
|评论对象|仅公开提示词支持评论|
|评论内容|纯文本，最多 500 字|
|回复|支持对评论进行回复，展示为两级结构（评论 + 回复列表）|
|排序|默认按时间正序（最早在前）；支持切换为最新在前|
|删除|评论者本人和提示词作者均可删除评论|
|权限|登录用户可评论，游客点击评论时弹出登录提示|

#### 3.4.3 Fork / 衍生创作

|项目|说明|
|---|---|
|Fork 操作|在公开提示词详情页，点击「基于此创建」按钮|
|Fork 行为|将该提示词的名称、内容、标签、适用模型、使用方法复制一份到自己的库中，进入编辑页面|
|衍生标注|Fork 后的提示词自动记录来源，详情页展示「基于 @原作者 的提示词改编」|
|来源可追溯|点击来源标注可跳转到原始提示词|
|原作者可见|原提示词详情页展示「被 Fork N 次」|
|独立性|Fork 后的提示词完全独立，原始提示词的修改/删除不影响衍生版本|

## 五、版本规划

### V1（MVP）

- 用户注册 / 登录 / 个人中心
- 提示词 CRUD + 文件夹管理 + 置顶
- 提示词广场 + 分类导航 + 排序筛选搜索
- 点赞、收藏、一键复制、分享
- 评论系统
- Fork / 衍生创作
- 举报机制 + 敏感词过滤
- 导入 / 导出

### V2

- 第三方登录（Google / GitHub）
- 管理员后台 + 内容审核系统
- 关注系统 + 关注动态 Feed
- 排行榜（周榜 / 月榜 / 作者榜）
- 相关推荐算法
- 回收站功能
- 用户个人主页增强
