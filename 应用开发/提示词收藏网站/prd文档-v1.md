# 提示词收藏网站 - 需求文档

## 一、项目概述

### 1.1 项目名称

**PromptVault** — 高品质提示词收藏与分享平台

### 1.2 项目定位

一个面向 AI 用户的提示词管理与分享平台，用户可以收藏、管理自己的提示词，也可以将优质提示词分享到公共广场供他人发现和使用。

### 1.3 核心价值

- **个人管理**：提供私有提示词库，方便个人积累和复用
- **社区分享**：优质提示词可以公开到广场，形成社区生态
- **效果可视**：支持上传效果展示（图片/视频），让提示词效果一目了然
- **使用指引**：支持 Markdown 格式的使用说明，降低上手门槛

---

## 二、用户角色

|角色|说明|
|---|---|
|游客|可浏览提示词广场（公开内容），不可上传、收藏、评价|
|注册用户|可上传、管理自己的提示词，浏览广场，收藏/点赞他人提示词|
|管理员|后台管理，审核内容，管理用户（V2 迭代）|

## 三、功能模块

### 3.1 用户系统

#### 3.1.1 注册

|项目|说明|
|---|---|
|注册方式|邮箱 + 密码注册|
|必填字段|邮箱、密码、用户昵称|
|密码要求|最少 8 位，需包含字母和数字|
|邮箱验证|发送验证码/验证链接，验证后激活账号|
|防重复|邮箱唯一性校验|
|扩展（V2）|支持 Google / GitHub 第三方登录|

#### 3.1.2 登录

|项目|说明|
|---|---|
|登录方式|邮箱 + 密码|
|登录态维持|JWT Token，有效期 7 天，支持「记住我」延长至 30 天|
|安全策略|连续 5 次登录失败锁定 15 分钟|
|退出登录|清除本地 Token|

#### 3.1.3 个人中心

| 项目   | 说明                    |
| ---- | --------------------- |
| 头像   | 支持上传自定义头像，默认生成字母头像    |
| 昵称   | 可修改                   |
| 个人简介 | 选填，最多 200 字           |
| 修改密码 | 需验证原密码                |
| 数据统计 | 显示：我的提示词数量、获赞总数、被收藏总数 |
|      |                       |

### 3.2 提示词管理（核心模块）

#### 3.2.1 提示词数据结构

|字段|是否必填|类型|说明|
|---|---|---|---|
|提示词名称|✅ 必填|文本|最多 100 字符|
|提示词内容|✅ 必填|长文本|提示词正文，最多 5000 字符|
|分类标签|❌ 选填|标签（多选）|从预设标签中选择或自定义，最多 5 个|
|适用模型|❌ 选填|标签（多选）|如 ChatGPT / Claude / Midjourney / Stable Diffusion 等|
|效果展示|❌ 选填|图片或视频|图片最多 9 张（每张 ≤ 5MB），视频最多 1 个（≤ 50MB）|
|使用方法|❌ 选填|Markdown|支持完整 Markdown 语法，实时预览|
|公开状态|❌ 默认私有|开关|私有：仅自己可见；公开：展示到提示词广场|
|创建时间|自动|时间戳|系统自动记录|
|更新时间|自动|时间戳|修改时自动更新|

#### 3.2.2 创建提示词

- 弹窗或独立页面形式
- 表单布局清晰，必填项有明确标识（红色星号）
- 提示词内容区域支持代码编辑器风格（等宽字体、行号显示）
- 效果展示支持拖拽上传、粘贴上传
- 使用方法区域提供 Markdown 编辑器，支持分栏实时预览
- 支持保存为草稿

#### 3.2.3 编辑提示词

- 可修改所有字段
- 修改后记录更新时间
- 公开状态可随时切换

#### 3.2.4 删除提示词

- 需二次确认弹窗
- 删除后不可恢复（V2 考虑回收站功能）

#### 3.2.5 提示词详情页

- 顶部：名称 + 作者信息 + 发布时间 + 标签
- 提示词内容区域：带一键复制按钮（点击后按钮变为 ✓ 已复制）
- 效果展示区域：图片轮播 / 视频播放器
- 使用方法区域：Markdown 渲染展示
- 底部操作栏：点赞、收藏、分享链接

---

### 3.3 列表视图切换

#### 3.3.1 双列表切换机制

页面顶部提供两个切换按钮（Tab 风格），高亮当前选中项：

|视图|图标建议|说明|
|---|---|---|
|**我的提示词**|📁 / 个人图标|展示当前用户自己创建的所有提示词（含公开和私有）|
|**提示词广场**|🌐 / 地球图标|展示所有用户公开的提示词|

#### 3.3.2 我的提示词

|功能|说明|
|---|---|
|列表内容|显示自己所有提示词（公开+私有）|
|排序|默认按更新时间倒序；支持切换：创建时间、名称字母序|
|筛选|按公开状态（全部/公开/私有）、按标签、按适用模型|
|搜索|支持按名称和内容模糊搜索|
|快捷操作|每个卡片上有：编辑、删除、切换公开状态的快捷操作|
|空状态|显示引导文案 + 创建按钮："还没有提示词，立即创建第一个吧！"|

#### 3.3.3 提示词广场

|功能|说明|
|---|---|
|列表内容|显示所有用户公开的提示词|
|排序|默认按热度（点赞+收藏加权）；支持切换：最新发布、最多点赞、最多收藏|
|筛选|按分类标签、按适用模型|
|搜索|全局搜索：名称 + 内容 + 标签|
|卡片信息|名称、作者、标签、点赞数、收藏数、缩略图（如有）|
|快捷操作|点赞、收藏|
|游客可见|游客可浏览列表和详情，但点赞/收藏时弹出登录提示|

#### 3.3.4 我的收藏（附加 Tab，V1 可选）

| 功能   | 说明         |
| ---- | ---------- |
| 列表内容 | 显示用户收藏的提示词 |
| 操作   | 取消收藏       |

---

### 3.4 互动功能

|功能|说明|
|---|---|
|点赞|每个用户对同一提示词只能点赞一次，可取消|
|收藏|每个用户对同一提示词只能收藏一次，可取消|
|一键复制|复制提示词内容到剪贴板|
|分享|生成提示词详情页的分享链接|

### 4.3 视觉风格

|维度|规范|
|---|---|
|整体风格|现代简约，深色/浅色主题切换（默认深色，科技感强）|
|主色调|渐变紫蓝色（#6C5CE7 → #0984E3），传递 AI / 科技感|
|背景|深色主题：#0F0F23；浅色主题：#F8F9FA|
|卡片|圆角 12px，轻微投影，hover 时上浮 + 边框发光效果|
|字体|英文 Inter / 中文 思源黑体；提示词内容用等宽字体（JetBrains Mono）|
|动效|页面切换淡入淡出、卡片加载瀑布流动画、按钮点击微交互|
|图标|使用 Lucide Icons 或 Phosphor Icons，线条风格统一|
|响应式|完整适配桌面端、平板端、移动端|

### 4.4 关键交互细节

| 交互       | 说明                                   |
| -------- | ------------------------------------ |
| 一键复制反馈   | 点击复制按钮后，按钮变为 ✅「已复制」，1.5秒后恢复          |
| Tab 切换   | 带底部滑块动画，切换时列表有淡入过渡                   |

| Toast 提示 | 操作成功/失败统一用右上角 Toast，3秒自动消失           |
| 深色/浅色切换  | 顶部导航栏太阳/月亮图标，切换时整体过渡动画               |
|          |                                      |
